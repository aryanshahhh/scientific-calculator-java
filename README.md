# Scientific Calculator

A simple scientific calculator made with Java Swing. It has a classic desktop look and works with mouse or keyboard.

## What it can do

- Add, subtract, multiply, and divide
- Use brackets, powers, square roots, and factorials
- Calculate sin, cos, tan, log, and ln
- Switch between degrees and radians
- Use π, e, percentages, and reciprocal

## Run it

You need Java 17 or newer. Download `ScientificCalculator.jar`, then run:

```text
java -jar ScientificCalculator.jar
```

Or compile the source:

```text
javac -encoding UTF-8 ScientificCalculator.java
java ScientificCalculator
```

Enter calculates, Backspace deletes, and Escape clears. For functions, type a number inside brackets, such as `sin(30)`.
